# 下一轮独立任务：ASR Benchmark 结果可信度

本轮只修复服务生命周期与 Windows 集成测试，不改变 ASR 结果语义。

下轮需要共同处理：

1. **响应有效性**：验证 HTTP、响应结构和识别文本，空内容、错误内容或不完整响应
   不能计作成功；保留可定位到配置和样本的失败原因。
2. **完整样本比较**：固定同一份样本清单并记录总数、成功数、失败/跳过数；不同
   配置必须基于相同完整样本集合比较，不能以少跑或跳过困难样本获得更好结果。
3. **排名规则**：明确完整成功、部分失败、全失败和中止的参赛资格、排序及展示；
   先定义并测试正确性约束，再比较 RTFx/耗时，导出结果保留样本覆盖情况。

验收应覆盖空响应、非法响应、单样本失败、部分样本缺失、中止和完整成功的对照，
证明不完整或无效结果不会超过有效的完整结果。
