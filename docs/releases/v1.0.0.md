# LlamaHelper v1.0.0

首个正式版本，面向 Windows 11 x64，提供无需 Python 的单文件桌面程序。

## 主要功能与修复

- 图形化配置、启动 llama-server，监控资源与推理速度，管理参数预设及日志。
- 统一首次启动和重启的 API 健康检查；每次启动固定参数快照，隔离旧进程、
  旧健康检查和旧定时器的迟到回调。停止、超时、提前退出和应用关闭时有序清理，
  失败后可重新启动。
- Windows 假服务器进程与主窗口集成测试实际执行；关键生命周期测试缺失、
  跳过或失败会阻止 EXE 打包和 Release 发布。
- 翻译挂件支持停靠、文本/图片翻译、OCR 预设与长结果滚动。
- ASR 性能指标统一命名为 RTFx（音频时长 ÷ 识别耗时，越大越好），
  同步界面、README 和 CSV 列名。
- 项目代码以 MIT 许可证发布；许可证也包含于 EXE 的打包资源中。

## 使用与下载

下载并运行 `LlamaHelper.exe`，选择自行准备的 llama-server 与 GGUF 模型。
llama-server、模型、CUDA 运行时不包含在下载中。配置文件与预设保存在程序目录，
请将 EXE 放在具有写入权限的文件夹中。

附件 `LICENSE.txt` 为项目许可证，`windows.xml` 为本次构建的 JUnit 测试报告，
`SHA256SUMS.txt` 提供上述附件及 EXE 的 SHA-256 校验值。

## 当前限制

- 自动验证使用假服务器，不代表真实 GPU、模型和手动 EXE 界面验收。
- ASR 响应有效性、完整样本比较与排名资格规则仍为下一轮独立任务，
  见仓库中的 `docs/next-round-tasks.md`。
- 第三方依赖、llama-server 和模型沿用各自许可证。
