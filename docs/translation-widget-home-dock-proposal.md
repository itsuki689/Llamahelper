# 翻译挂件坞站构想

> 状态：已搁置，暂不实现  
> 记录日期：2026-08-25

## 背景

计划在 LlamaHelper 左侧栏底部增加一个白色空缺，使其成为翻译挂件的“Home Dock（主坞站）”。启动翻译挂件后，挂件通过动画在该位置出现；随后可以从坞站释放到桌面，也可以从桌面返回坞站。

这个设计的目标不是增加一个普通启动按钮，而是强化“dockable desktop widget”的产品概念，让挂件拥有明确的停驻位置、启动来源和返回位置。

## 推荐交互

### 1. 未启动

- 侧栏底部显示一个白色空缺槽位。
- 槽位采用细白色圆环和深色内部，不使用纯白实心圆。
- 不添加阴影，避免出现灰色投影或悬浮感。

### 2. 启动

- 用户仍从“翻译挂件”设置页点击“启动挂件”。
- 槽位白环先轻微扩张。
- 黑色圆形挂件从中心以 `0.72 → 1.0` 的比例生成。
- 内部白圈同步绘制完成，动画时长约 `260ms`，缓动使用 `OutCubic`。

### 3. 停驻

- 挂件启动后先停留在侧栏坞站内。
- 鼠标移入时，内部白圈沿用现有扩张动画，表示挂件可以被释放。
- 白圈应始终位于黑色圆形内部，黑色圆形外缘另有独立细白边。

### 4. 释放到桌面

- 左键点击或向外拖动坞站中的挂件，将其释放到桌面。
- 挂件从坞站的全局屏幕坐标平滑移动到上次保存的位置。
- 首次启动时，默认停在主窗口右侧的合理位置。

### 5. 桌面运行与返回

- 挂件位于桌面时，侧栏恢复为空槽状态。
- 点击空槽可以将挂件唤到前台。
- 后续可增加“收回”动作，使桌面挂件播放返回动画并重新进入坞站。

## 视觉规格建议

现有翻译挂件的尺寸可以直接复用：

- 挂件窗口：`66 × 66px`
- 黑色圆形主体：`52px`
- 内部白圈：`36px`
- 坞站区域：约 `66 × 66px`
- 侧栏底部间距：`24–28px`
- 空槽外框：`1px` 半透明白色
- 动画风格：短促、克制、无弹跳过度，保持 Apple 风格

## 技术方案

不建议直接把现有 `TranslateWidget` 重新挂载为侧栏子控件。它是独立透明桌面窗口，重新设置 Qt 父窗口可能破坏置顶、透明绘制、拖曳和屏幕边缘吸附。

建议采用“视觉代理 + 独立桌面窗口”的结构：

1. 在侧栏中新增 `WidgetHomeDock`，负责绘制空槽和停驻状态下的挂件代理。
2. 真正的 `TranslateWidget` 继续保持独立顶层窗口。
3. 释放时，通过 `WidgetHomeDock.mapToGlobal()` 计算坞站的全局坐标。
4. 将桌面挂件初始几何位置设为坞站对应的全局矩形。
5. 桌面挂件显示后，在同一帧隐藏侧栏代理，再播放几何动画，从视觉上形成同一个挂件飞出主窗口的效果。
6. 返回坞站时执行相反过程，避免同时显示两个挂件造成闪烁。

坞站状态建议与翻译挂件现有状态机分离：

```text
EMPTY → MATERIALIZING → HOME → RELEASING → FLOATING → RETURNING
```

现有翻译挂件的 `IDLE`、`PROCESSING`、`RESULT`、`DOCKED` 等状态保持不变。

## 实现时需要验证

- 主窗口移动、缩放或最大化后，全局坐标转换仍然准确。
- Windows DPI 缩放和多显示器环境下动画位置正确。
- 动画交接时不存在两个挂件同时显示或单帧闪烁。
- 重复点击启动按钮不会创建多个桌面挂件实例。
- 主窗口关闭时，坞站代理和桌面挂件能够正确清理。
- 为坞站空槽、生成、释放、返回四种状态增加截图测试。

## 当前决定

该构想仅作为后续设计备选保存，目前搁置，不进入实现计划，不改变现有翻译挂件启动和运行方式。
